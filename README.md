# فریمان

فرم چندمرحله‌ای فارسی برای جمع‌آوری **نیازمندی‌های صاحب فروشگاه تلویزیون** — نه اطلاعات خرید مشتری. صاحب فروشگاه می‌گوید سایت فروش تلویزیون چه امکاناتی باید داشته باشد: کاتالوگ، تجربه خرید، پرداخت، ارسال و پنل مدیریت.

## چه چیزی جمع می‌شود؟

- معرفی فروشگاه و وضعیت سایت فعلی
- برندها و بازه سایزهای کاتالوگ
- امکانات سایت برای مشتری نهایی (فیلتر، مقایسه، پیکربندی مرحله‌ای، چت و ...)
- درگاه پرداخت، ارسال، نصب و گارانتی
- ابزارهای پنل مدیریت برای خود فروشگاه
- سبک طراحی و سایت‌های مرجع

**شماره موبایل مشتری یا جزئیات خرید تلویزیون گرفته نمی‌شود.**

## اجرا

```bash
cp .env.example .env
npm install
npm run setup
npm run dev
```

سایت روی `http://localhost:3000` باز می‌شود.

### حساب مدیر

- ایمیل: `admin@fariman.ir`
- رمز: `Admin1234!`

صاحب فروشگاه با ایمیل و رمز ثبت‌نام می‌کند (بدون تأیید ایمیل)، فرم را مرحله‌به‌مرحله پر می‌کند و پیش‌نویس ذخیره می‌شود. بعد از «ثبت نهایی» دیگر نمی‌تواند فرم را دوباره ویرایش کند.
