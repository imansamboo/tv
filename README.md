# پارس‌تی‌وی

فرم چندمرحله‌ای فارسی برای تجمیع نیاز مشتری یک فروشگاه تلویزیون، همراه با حساب کاربری، ذخیره پیش‌نویس، قفل بعد از ثبت نهایی، چت‌بات کمپین و پنل مدیریت.

## چرا این فیلدها؟

با بررسی مسیر خرید تلویزیون در فروشگاه‌هایی مثل دیجی‌کالا، تکنولایف، سامسونگ و بست‌بای این نیازها تکرار می‌شود:

- انتخاب سایز صفحه (۳۲ تا ۸۵ اینچ) که قیمت را عوض می‌کند
- برند، نوع پنل، رزولوشن، سیستم‌عامل و گیمینگ
- نصب دیواری / پایه، براکت و جمع‌آوری تلویزیون قبلی
- هزینه ارسال، کاور محافظ و بیمه حمل **قبل از ورود به درگاه پرداخت**
- شماره موبایل برای کمپین و پیگیری ارسال

## اجرا

```bash
cp .env.example .env
npm install
npm run setup
npm run dev
```

سایت روی `http://localhost:3000` باز می‌شود.

### حساب مدیر

- ایمیل: `admin@parstv.ir`
- رمز: `Admin1234!`

مشتری با ایمیل و رمز ثبت‌نام می‌کند (بدون تأیید ایمیل)، فرم را مرحله‌به‌مرحله پر می‌کند و پیش‌نویس ذخیره می‌شود. بعد از «ثبت نهایی و ورود به درگاه» دیگر نمی‌تواند فرم را دوباره ویرایش کند.
